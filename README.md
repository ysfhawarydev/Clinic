# 🏥 Clinic Project

## 📌 Overview
This is a modern and fully responsive clinic website built using only HTML and CSS.  
The project focuses on creating a clean, professional, and user-friendly medical interface with a well-structured layout and elegant design.

---

## ✨ Features
- Fully responsive design for all devices  
- Clean and professional medical UI  
- Well-structured layout using semantic HTML  
- Simple and easy navigation  
- Modern and elegant CSS styling  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  

---

## 🎯 Purpose
This project was created to practice frontend development skills and improve UI/UX design for real-world websites using only HTML and CSS.
